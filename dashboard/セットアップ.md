# 保護者のスマホで記録を見るための設定（10分ほど）

ふだんのドリルは、この設定をしなくてもこれまでどおり動きます（記録は iPad の中にたまります）。
ここでは、その記録を **保護者のスマホからも見られるようにする** 設定をします。

作るもの：

- 記録をためる **Google スプレッドシート**（ご家庭の Google アカウント）
- 記録を受けとる **Apps Script**（スプレッドシートに付属するプログラム）

送るのは学習の記録だけです（日付・教科・分野・問題数・正解数・時間・項目ごとの正誤）。
氏名や連絡先などは送りません。名前の欄は、きょうだいで使うときの区別のための、好きな文字列です。

---

## 1. スプレッドシートを作る

1. パソコン（またはスマホのブラウザ）で https://sheets.new を開く
2. できた表の名前を、わかりやすく変える（例：`勉強の記録`）

## 2. プログラムを貼りつける

1. メニューの **「拡張機能」→「Apps Script」** を開く
2. すでに書かれているコード（`function myFunction() {}` など）を **すべて消す**
3. このフォルダの **`コード.gs`** の中身を、すべてコピーして貼りつける
4. 上のほうにある

   ```js
   const KEY = 'あいことば';
   ```

   の `あいことば` を、**自分で決めた合言葉**に書きかえる
   （例：`kazoku2026`。半角の英数字がおすすめです。あとで iPad とスマホに同じものを入れます）
5. フロッピーのアイコン（保存）を押す

## 3. 公開する（デプロイ）

1. 右上の **「デプロイ」→「新しいデプロイ」**
2. 歯車（種類の選択）→ **「ウェブアプリ」**
3. 次のように設定する
   - **説明**：なんでもよい（例：`勉強の記録`）
   - **次のユーザーとして実行**：`自分`
   - **アクセスできるユーザー**：**`全員`**
     （※「全員」でも、合言葉が合わないデータは受けつけません）
4. **「デプロイ」** を押す
5. 「承認が必要です」と出たら、**「アクセスを承認」→ 自分の Google アカウントを選ぶ**
6. **「このアプリは Google で確認されていません」**（英語だと **Google hasn't verified this app**）
   という画面が出ます。**これは正常です。そのまま進めて大丈夫です。**
   - 自分で書いたプログラムを、自分のアカウントで動かすときには必ず出ます
     （Google の審査を受けた「みんなに配るアプリ」ではない、という意味の注意書きです）
   - 進み方：左下の **「詳細」**（**Advanced**）→
     **「（プロジェクト名）に移動（安全ではないページ）」**（**Go to …（unsafe）**）→
     いちばん下の **「許可」**（**Allow**）
   - ここで求められるのは、**スプレッドシートの参照・編集**と、
     **ウェブアプリとして外部とやりとりすること**の2つだけです。
     Gmail や連絡先など、身に覚えのない権限が出たときは、貼りつけたコードがちがう
     可能性があるので、いったん止めてください
   - 「詳細」が出てこないときは、学校や会社のアカウント（Workspace）で
     管理者に止められていることがあります。**個人の Gmail アカウント**で作り直すのが早いです
7. 出てきた **ウェブアプリの URL をコピー** する
   （`https://script.google.com/macros/s/……/exec` という形）

## 4. iPad に入れる（息子さんの端末）

1. iPad の Safari でドリルを開き、上のリンクから **「がんばり」** を開く
2. いちばん下の **「保護者用の設定（記録を送る）」** を開く
3. **URL**：3 でコピーしたもの
   **合言葉**：2 で決めたもの
   **名前**：好きな文字列（例：`たろう`）
4. **「保存する」→「いま送る」** を押す
   「未送信 ◯件」が 0 になれば成功です

## 5. 保護者のスマホに入れる

1. スマホのブラウザで **保護者ページ** を開く
   `https://ynghrksk-cmd.github.io/study-drill/oya.html`
2. いちばん下の **「送信の設定（保護者用）」** を開く
3. iPad と **同じ URL と合言葉** を入れて「保存する」
4. 上の **「読みこむ」** を押す → 記録が出てくれば完了
5. ブラウザの共有ボタンから **「ホーム画面に追加」** しておくと、アプリのように開けます

---

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「Google hasn't verified this app」と出る | 正常です。「詳細（Advanced）」→「…に移動（unsafe）」→「許可（Allow）」で進みます |
| 「未送信」が減らない | URL の最後が `/exec` になっているか。合言葉が iPad と同じか |
| 保護者ページが空のまま | 「読みこむ」を押したか。合言葉が iPad と同じか。iPad 側で1回「いま送る」をしたか |
| 記録が古いまま | iPad でドリルを1回やると送信されます。iPad が機内モードやオフラインだと、次にネットにつながったときに送られます |
| プログラムを直した | **「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→ バージョン「新バージョン」→「デプロイ」** をしないと反映されません |

## 記録を消したいとき

スプレッドシートの行を消せば、その記録は消えます（`sessions` が1回ごと、`items` が項目ごと）。
iPad の中の記録は、Safari の「履歴とWebサイトデータを消去」で消えます（復習ボックスも消えます）。
