# study-drill

中学1年生向けの勉強ドリル（iPad の Safari で使う）。

## ドリル

- 数学ドリル：https://ynghrksk-cmd.github.io/study-drill/
- 理科ドリル：https://ynghrksk-cmd.github.io/study-drill/science.html
- 国語ドリル：https://ynghrksk-cmd.github.io/study-drill/kokugo.html
- 社会ドリル：https://ynghrksk-cmd.github.io/study-drill/shakai.html
- 英語ドリル：https://ynghrksk-cmd.github.io/study-drill/eigo.html

それぞれ1つの HTML ファイルで完結していて、問題は毎回自動で作られます。
まちがえた問題は復習ボックスに入り、1日後・3日後・1週間後…と間をあけて出しなおされます。

トップ画面では「今日の復習 / にがて集中 / 新しいところ」から自分でえらべます。
レベルは じどう／きほん／おうよう。じどうは、よくできている分野だけ おうよう の問題をまぜます。
間をあけて思い出せた数に合わせて、教科ごとのランク（数学は計算の塔、英語は The Road…）が上がります。

## 記録を見る

- がんばりの記録（子ども向け）：https://ynghrksk-cmd.github.io/study-drill/kiroku.html
- 学習の記録（保護者向け）：https://ynghrksk-cmd.github.io/study-drill/oya.html

記録はふだん、使っている端末の中だけに残ります。
保護者のスマホからも見たいときは、`dashboard/セットアップ.md` の手順で
Google スプレッドシートに記録を送る設定ができます（設定しなければ完全にオフラインで動きます）。
